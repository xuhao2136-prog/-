# 调脂活脉颗粒治疗高脂血症的中药新药研发与临床转化

围绕调脂活脉颗粒开展工艺优化、质量标准提升、药效机制研究与临床转化的课题文档仓库。

## 研究背景与目标

本仓库用于整理“调脂活脉颗粒治疗高脂血症的中药新药研发与临床转化”课题申报与研发资料。原仓库仅包含一个旧版 Word `.doc` 二进制文件，不利于版本管理、差异审阅与协作维护。

本次整理的目标是：

- 保留原始 `.doc` 归档版本，避免资料丢失；
- 将可提取正文转换为可审阅、可 diff 的 Markdown 文档；
- 按章节组织课题内容，便于后续补充数据、图表和参考文献；
- 为后续类似 Word 文档整理提供可复用脚本与目录约定。

## 使用与贡献说明

- 建议优先在 `docs/` 下直接修改 Markdown 内容，以便保留可审阅的变更历史。
- 原始申报材料请保存在 `docs/legacy/`，避免直接覆盖历史文件。
- 研究数据、图片与参考资料请分别放入 `data/`、`figures/`、`refs/`。
- 若新增 Word 文档，可优先使用 `scripts/doc_to_markdown.py` 提取文本后再人工校对。
