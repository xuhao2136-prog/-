项目核心内容介绍

项目研究背景

高脂血症是动脉粥样硬化性心血管疾病的重要危险因素，现有治疗仍存在他汀不耐受及心血管残余风险。开发安全、有效、可转化的中药复方制剂，具有明确临床需求和产业价值。

项目主要研究内容

围绕调脂活脉颗粒降低 LDL-C 的效应基础，重点解决工艺稳定性、质量标志物筛选及作用机制不清等问题，阐明 cutC—TMAO 与 FXR/SHP—CYP7A1 双通路调控机制。

项目研究基础

项目已取得院内制剂批号并申请发明专利，完成药效学、多组学测序及实验验证，相关论文已被北大核心期刊录用；团队由临床医师、药学领域基础科研人员及临床统计学等专业人员组成。

预期标志性成果

形成优化生产工艺、全过程质量标准及双通路机制证据，完成探索性临床评价，申请相关专利和新药注册成果，建立院内制剂向中药新药转化的示范方案。

与国内外先进技术水平对标情况

团队已掌握院内制剂研发、药效评价、转录组及靶点验证技术。国内相关研究多停留于单一质控和相关性机制，国外侧重单靶点降脂药物，本项目拟实现复方效应关联质控与机制因果验证。

国内外现状及趋势分析

包括本项目相关国内外总体研究情况和水平、最新进展和发展前景。限 1000 字以内（不包括表格），并填写下表。

高脂血症是动脉粥样硬化性心血管疾病（ASCVD）的重要可干预危险因素，低密度脂蛋白胆固醇（LDL-C）是国内外公认的首要降脂靶点。2025 年 ESC/EAS 更新及 2026 年 ACC/AHA 血脂管理指南进一步强化基于总体心血管风险分层的早期、长期和强化降脂理念，治疗模式由单纯使用他汀类药物逐步转向“他汀为基础、非他汀药物联合”的个体化管理；依折麦布、PCSK9 抑制剂、inclisiran、贝派地酸等药物不断拓展临床应用，研究重点亦由单一 LDL-C 控制延伸至非 HDL-C、载脂蛋白 B、脂蛋白（a）及残余心血管风险管理。

国内《中国血脂管理指南（2023年）》同样明确 LDL-C 为首要干预靶点，并依据 ASCVD 危险分层确定不同控制目标。近年来，中药复方及中西医结合干预高脂血症的研究持续增加。2024 年一项纳入 23 项随机对照试验、7316 例患者的系统评价显示，中药联合常规治疗可改善 LDL-C、总胆固醇和甘油三酯等指标，并提示潜在心血管获益。但现有研究仍普遍存在样本量有限、处方及证候异质性较大、制备工艺与质量标准不统一、主要终点选择不规范、长期随访和安全性证据不足等问题，尚需高质量临床研究进一步验证。

我国中药研发正由经验总结向规范化、证据化和产业化加速转型。《中药注册管理专门规定》建立了“中医药理论—人用经验—临床试验”相结合的审评证据体系，明确支持名老中医经验方和医疗机构中药制剂的新药转化，并鼓励真实世界研究、生物标志物及全过程质量控制。2025 年国务院办公厅相关意见进一步提出加强名医验方和医疗机构中药制剂挖掘转化，突出临床价值评价、质量标准提升和科技成果产业化。

调脂活脉颗粒源于名老中医经验方，已有院内制剂批号、备案资料及临床应用基础，具有处方固定、人用经验可追溯和转化路径较明确的优势。项目拟以 LDL-C 降低及心血管危险因素改善为核心临床价值，通过规范整理人用经验、优化制备工艺、建立多成分质量控制体系、开展药效机制及循证临床评价，着力解决现有中药降脂研究证据等级和质量一致性不足等问题，具备向中药创新药转化并形成特色降脂产品的良好发展前景。

研究内容及目标

一、项目立项背景和意义

（一）项目提出的背景

高脂血症是动脉粥样硬化性心血管疾病的重要危险因素，低密度脂蛋白胆固醇升高与冠心病、脑卒中等心脑血管事件密切相关。现有治疗以他汀类及联合降脂药物为主，但部分患者仍存在疗效不充分、药物不耐受或长期依从性不足等问题。国家持续支持名老中医经验方和医疗机构中药制剂的挖掘、评价与成果转化。调脂活脉颗粒具有明确的中医理论和院内应用基础，符合中药复方制剂新药研发及临床转化方向。

（二）项目立项意义和必要性

本项目具有明确的临床、科学与转化价值。临床上，调脂活脉颗粒具有多成分、多靶点协同作用特点，有望为他汀不耐受及仍存在残余心血管风险的高脂血症患者提供新的治疗选择，进一步改善 LDL-C 水平及相关危险因素。科学上，拟围绕“肠道菌群 cutC—TMAO”与“胆汁酸 FXR/SHP—CYP7A1”双通路，系统阐明其调脂及心血管保护机制，为中药复方“化痰祛瘀”治法的现代科学阐释提供依据。转化上，针对院内制剂工艺粗放、质量控制单一、作用机制不清等瓶颈，开展工艺优化、质量标准提升和适应症拓展，契合国家“三结合”审评政策及山西省中医药产业高质量发展部署，可形成院内制剂向中药新药转化的示范路径。

（三）项目现有的工作基础和优势

调脂活脉颗粒由虎杖、黄连、薤白、蒲黄、赤芍和陈皮组成，源于名老中医经验方，主要用于 LDL-C 升高型高脂血症，处方固定，治法特点明确。该制剂已取得院内制剂批号，具备相应备案资料及临床应用条件，为系统整理人用经验、评价有效性与安全性提供了基础。项目可依托现有制剂、临床病例和诊疗平台，进一步开展工艺、质量、药效、安全性及临床研究，具有研发起点较高、临床需求明确、研究连续性较好和成果转化路径清晰等优势。

二、项目研究内容、研究方法及技术路线

（一）项目的主要研究内容

1. 拟解决的关键问题

本项目拟聚焦三个相互衔接的科学问题：其一，系统明确调脂活脉颗粒对 LDL-C 及动脉粥样硬化相关危险因素的干预效应、潜在获益人群及效应关联物质基础；其二，阐明该制剂是否通过调控“肠道菌群 cutC—TMA/TMAO”与“胆汁酸 FXR/SHP—CYP7A1”两条关键代谢通路发挥肠—肝协同调脂作用，并解析二者之间的关联结构与因果链条；其三，在现代脂质代谢、炎症调控与血管保护研究框架下，构建中医“化痰祛瘀、通脉调脂”治法的可验证生物学解释。已有研究表明，cutC 是肠道菌群介导胆碱转化为 TMA 的关键酶，FXR/SHP—CYP7A1 轴是调节胆汁酸稳态与胆固醇代谢的重要信号网络，为本项目提出的机制假说提供了明确的理论支撑，但其在本复方中的调控方向、作用强度及组织特异性仍需通过系统实验加以证实。

围绕上述科学问题，本项目拟同步解决以下关键技术问题：一是明确院内制剂从原药材到成品的关键工艺参数、成分传递规律及批间稳定性控制要点；二是建立能够兼顾复方整体特征、关键成分信息与效应相关性的质量评价体系；三是完成既往临床应用资料的规范化整理与证据化表达，形成能够支撑临床定位、质量提升及中药新药转化的系统证据链。

2. 主要研究内容
  1. 名医经验传承与人用经验规范化研究。 系统梳理处方传承脉络、组方依据、功能主治、制剂演变及临床应用规范，构建结构化的人用经验数据库。在既往临床资料基础上开展回顾性队列研究，重点评价 LDL-C、TC、TG、HDL-C、非 HDL-C、ApoB、中医证候积分及肝肾功能等指标的变化趋势，分析剂量、疗程、合并用药、证候特征与疗效及安全性的关联性，进而明确潜在获益人群、优势证候及推荐用药方案。
  2. 制备工艺优化与中试放大研究。 围绕提取、浓缩、干燥及制粒等关键环节，采用以浸膏得率、指标成分转移率、干膏性质、颗粒成型率、溶化性、吸湿性及稳定性为核心的综合评价体系，优化关键工艺条件并界定其允许波动范围；在此基础上完成中试放大与连续 3 批工艺验证，形成稳定、可重复且具备产业化转化条件的生产工艺。
  3. 质量标准提升与质量标志物筛选研究。 构建覆盖“药材—中间体—成品”的全过程质量控制体系，综合应用 UPLC/HPLC 指纹或特征图谱、高分辨质谱成分解析及多成分定量方法，结合化学计量学、谱效关系和体内暴露信息，筛选与调脂效应密切相关的候选质量标志物；同步完善药材鉴别、含量测定、有害物质限度、微生物限度及稳定性研究要求，建立批间一致性评价方法。
  4. 药效学与安全性系统评价。 采用高脂饮食诱导的高脂血症模型及 ApoE 基因敲除动脉粥样硬化模型开展剂量—效应研究，从血脂谱、肝脏脂质沉积、主动脉斑块形成、炎症反应、氧化应激、血管内皮功能及血小板活化等方面综合评价药效；结合肝细胞脂质蓄积和巨噬细胞泡沫化模型验证关键药效环节，并依据中药新药研发要求开展必要的安全药理和重复给药毒性研究。
  5. 双通路机制解析及因果验证研究。 通过宏基因组测序、cutC 功能基因定量及离体菌群发酵实验，评估产 TMA 菌群构成及胆碱向 TMA 的转化能力；采用靶向代谢组学检测胆碱、TMA、TMAO 及胆汁酸谱变化，并同步测定肝脏 FMO3 及肝、肠组织中 FXR、SHP、FGF15、CYP7A1 等关键节点的表达水平。进一步结合抗生素去菌、粪菌移植及 FXR 通路干预实验，验证菌群依赖性与关键信号轴的因果作用，构建“有效成分—肠道菌群—代谢物—靶点网络—调脂效应”作用链条。
  6. 临床有效性与安全性探索性评价。 基于人用经验整理结果及前期药学、药效研究基础，在标准生活方式干预和必要基础治疗背景下开展随机、双盲、对照的探索性临床研究，以 LDL-C 较基线变化率作为主要评价指标，同时观察血脂谱、ApoB、中医证候积分、TMAO、胆汁酸谱、炎症指标及安全性结局的变化。重点识别他汀不耐受或规范治疗后仍存在残余风险患者的潜在获益特征，为适用人群优化及后续注册临床研究设计提供依据；本阶段研究定位于探索性评价，不将心血管事件结局作为确证性结论。

（二）项目拟采取的研究方法和技术路线

1. 总体技术路线

按照“名医经验传承与人用经验整理—临床定位—制备工艺优化—质量标准提升—药效与安全性评价—双通路机制及因果验证—探索性临床评价—中药新药转化”的技术路线推进，形成中医药理论、人用经验、药学质量、非临床研究和临床证据相互印证的完整研发体系。

2. 研究方法
  1. 人用经验研究。 制定统一数据字典和病例报告表，对既往病例中的处方剂量、疗程、证候、合并用药、血脂指标和安全性信息进行标准化采集与数据治理。采用自身前后比较和回顾性队列分析，运用倾向评分、分层分析及敏感性分析控制混杂因素；根据疗效、证候和基线风险特征构建优势人群画像，为适应症、用法用量及临床试验方案提供依据。该研究路径与国家构建“中医药理论—人用经验—临床试验”相结合的中药审评证据体系相衔接。
  2. 工艺与质量研究。 运用质量源于设计理念识别关键质量属性和关键工艺参数，采用单因素试验结合正交设计或响应面法优化提取、浓缩、干燥和制粒条件，建立工艺设计空间；通过连续 3 批中试样品考察工艺稳定性和成分传递一致性。采用 UPLC/HPLC 指纹图谱、高分辨质谱成分解析及一测多评或多成分定量技术，结合主成分分析、聚类分析、谱效关系及入血成分研究筛选质量标志物，建立原料、中间体和制剂的全过程质量控制方法。
  3. 药效与安全性研究。 设置正常组、模型组、阳性药组及调脂活脉颗粒不同剂量组，分别采用高脂饮食模型评价降脂作用、采用 ApoE 基因敲除模型评价抗动脉粥样硬化及血管保护作用。通过血液生化、油红 O 染色、组织病理、免疫组化、Western blot 和 RT-qPCR 等技术评价脂质代谢、炎症、氧化应激及内皮损伤；按照非临床研究规范观察一般状态、血液学、血生化和脏器病理变化，确定安全剂量范围。
  4. 双通路机制研究。 采用宏基因组测序分析菌群组成和功能基因，利用 qPCR 定量 cutC，结合离体厌氧发酵、稳定同位素示踪和 LC-MS/MS 测定胆碱—TMA—TMAO 代谢能力；采用靶向胆汁酸代谢组学分析初级、次级及结合型胆汁酸变化。检测肝脏 FMO3、FXR、SHP、CYP7A1 及肠道 FXR、FGF15 等关键节点，通过多组学关联网络和中介效应分析筛选核心作用链条。进一步采用抗生素去菌和粪菌移植验证菌群依赖性，采用 FXR 激动剂、拮抗剂或细胞基因干预验证受体通路，推动机制研究由相关性分析向因果验证深入。
  5. 临床研究。 依据前期效应量估算样本量，采用随机、双盲、对照设计，按照他汀耐受情况、基线 LDL-C 水平和心血管风险进行分层随机。以 LDL-C 较基线变化率为主要终点，以其他血脂指标、中医证候积分、TMAO、胆汁酸谱、炎症指标及安全性为次要或探索性终点；采用意向性分析和符合方案集分析，建立独立的数据管理、研究监查、质量控制及不良事件判定流程。
3. 可行性与先进性分析

本项目来源于固定的名老中医经验方，已有院内制剂批号、备案资料及临床应用基础，处方、剂量和人用经验具有可追溯性，为临床定位、药效评价及新药转化提供了较好基础。项目所采用的工艺优化、色谱质谱、多组学、动物模型和临床评价方法相对成熟，可通过药学、药理、临床及生物信息学多学科协同实施。

本项目先进性主要体现在：一是将名医经验和真实临床应用资料转化为规范、可分析的人用经验证据；二是应用质量源于设计、体内暴露和谱效关系方法，实现由单一成分控制向复方整体质量及效应相关控制升级；三是将宏基因组、靶向代谢组与去菌、粪菌移植和受体通路干预相结合，避免仅依据网络药理学或组学相关性推断机制；四是贯通药学质量、药效机制和临床评价，构建“工艺稳定、质量可控、机制可释、疗效可证、转化可行”的闭环技术体系。

三、项目主要创新点

本项目以名老中医经验方调脂活脉颗粒为研究对象，围绕院内制剂向中药新药转化的关键瓶颈，构建“机制阐释—质量提升—临床转化”一体化创新体系。项目提出调脂活脉颗粒可能通过“肠道菌群 cutC—TMA/TMAO”与“胆汁酸 FXR/SHP—CYP7A1”双通路协同调控脂质代谢，并结合宏基因组、靶向代谢组、离体发酵、去菌、粪菌移植及通路干预开展因果验证，阐明“化痰祛瘀、通脉调脂”治法的现代科学内涵。同时，引入质量源于设计、指纹图谱、多成分定量、体内暴露及谱效关系等方法，建立“药材—中间体—成品”全过程、效应关联的质量控制体系。在此基础上，整合名医经验、人用经验、药学、药效、安全性及临床评价证据，形成工艺可放大、质量可控制、机制可解释、疗效可评价的院内制剂转化路径，为山西省医疗机构中药制剂优化升级及中药新药研发提供示范。

四、预期经济社会效益

项目的实施可产生的预期科学价值，社会、经济、生态效益。限 500 字以内。

预期形成调脂活脉颗粒工艺优化、质量标准、药效机制及临床评价等系列成果，明确其调控肠道菌群、TMAO 代谢和胆汁酸信号的作用基础，丰富中医药防治高脂血症及动脉粥样硬化的科学内涵，提升名老中医经验方的循证证据水平。社会效益方面，有望为 LDL-C 升高、他汀不耐受或规范治疗后仍存在残余风险的患者提供具有中医药特色的治疗选择，促进高脂血症规范管理和心血管疾病风险防控。经济效益方面，可推动院内制剂工艺标准化、规模化生产及中药新药成果转化，形成具有自主知识产权和市场竞争力的特色产品，带动山西道地药材种植、加工、制药及技术服务等产业链协同发展。项目采用规范化生产和全过程质量控制技术，有助于提高药材利用效率、减少生产损耗，兼具一定的生态和资源节约效益。

一、申报单位的已有工作基础、研究成果、研究队伍等

（一）项目申报单位在该研究方向的前期任务承担及验收情况、相关研究成果

山西中医药大学附属医院长期开展中医药防治高脂血症及动脉粥样硬化相关疾病的临床与基础研究，在名老中医经验传承、医疗机构中药制剂研发、药效评价及作用机制研究等方面具有较好的工作积累。项目核心制剂调脂活脉颗粒源于名老中医临床经验方，由虎杖、黄连、薤白、蒲黄、赤芍、陈皮组成，具有化痰祛瘀、通脉调脂之功，主要用于低密度脂蛋白胆固醇升高型高脂血症。该制剂已取得医疗机构中药制剂批号，并完成相关备案，处方组成、制备工艺、质量标准、功能主治及临床使用方案基本明确，具备持续开展优化升级和新药转化研究的合规基础。

围绕调脂活脉颗粒的知识产权保护及成果转化，本院已就其处方、制备工艺或临床用途申请国家发明专利，初步构建了自主知识产权保护体系，为后续技术转让、产品开发和中药新药注册奠定了基础。前期已开展调脂活脉颗粒药效学研究，通过高脂血症或动脉粥样硬化相关实验模型，对血脂水平、组织病理变化及相关生物学指标进行评价，结果提示该制剂具有改善脂质代谢和减轻相关病理损伤的作用。

在机制研究方面，项目组已采用转录组测序技术筛选调脂活脉颗粒干预后差异表达基因及相关信号通路，并结合生物信息学分析识别潜在关键靶点；进一步通过免疫荧光等实验方法对部分核心靶点及组织定位进行了验证，初步形成“整体药效评价—组学通路筛选—关键靶点验证”的研究链条。相关研究成果已获北大中文核心期刊论文录用，表明项目前期研究具有一定的系统性和学术基础。

本院已具备院内制剂制备、临床病例收集、动物实验、分子生物学检测和数据分析等研究条件，并形成中医临床、药学、药理、分子生物学及统计分析等多学科协作基础。上述成果为本项目进一步开展人用经验整理、工艺优化、质量标准提升、双通路机制验证及临床转化研究提供了可靠支撑。
